# PCG 會議翻譯：安裝與更新說明（給同仁與 IT）

[中文](安裝說明.md) · [English](INSTALL-GUIDE-en.md) · [Bahasa Indonesia](INSTALL-GUIDE-id.md) · [Tiếng Việt](INSTALL-GUIDE-vi.md)

最新版下載：**https://github.com/fairy715/PCG-live-whisper/releases/latest**

每一版的發布頁也有同樣的說明，並標明這一版可不可以用小更新包。

怎麼用在線上會議、上課、會後會議紀錄：見 [使用情境](使用情境.md)。

## 一、下載

1. 打開發布頁：https://github.com/fairy715/PCG-live-whisper/releases/latest
2. 在頁面下方「Assets」點 `PCG-Meeting-Translator-Setup-<版本>.exe` 下載（約 1.8 GB）。
   * 瀏覽器如果警告「這個檔案不常下載」，選「保留」（Edge：點「…」→「保留」）。
   * 檔案很大，也可以由 IT 放到公司共用資料夾或 Google Drive 再發給同仁。

## 二、安裝

1. 點兩下下載好的 exe。
2. 出現藍色視窗「Windows 已保護您的電腦」：
   * 點「其他資訊」，再按「仍要執行」。
   * 這是因為安裝檔沒有程式碼簽章，第一次一定會出現。
3. 如果出現選語言的視窗，選好按「確定」（通常會依 Windows 語言自動選好，不會出現）。
4. 安裝位置：預設 `D:\PCG-live-whisper`（沒有 D 槽就是 `C:\PCG-live-whisper`），不用改，按「下一步」→「安裝」。
   * 不需要系統管理員權限，也不需要網路。
5. 畫面顯示「正在安裝執行環境與模型」，約 3～10 分鐘，請不要關掉。
6. 完成：勾「立即開啟 PCG 會議翻譯」再按「完成」。桌面會多一個「PCG 會議翻譯」捷徑。

## 三、第一次使用

1. 點桌面的「PCG 會議翻譯」，瀏覽器會自動打開操作頁面（`http://localhost:19781/simple`）。
2. 第一次會有導覽，照著看一遍。
3. 即時字幕：選你說的語言 → 哪一種場合 → 對方說的語言 → 按「開始」（外語同仁選自己的語言就會自動選好）；錄音檔：上傳 → 處理完下載會議紀錄。
4. 頁面最下方會顯示版本（例如 v2026.11.5.r5），回報問題時請附上（點一下就會複製）。

## 四、更新

已經裝過的電腦**不用先移除**，設定、錄音、逐字稿都會保留：

* **一鍵更新（最簡單）**：能上網、或 IT 有設定公司共用資料夾的電腦，有新版時操作頁面上方會出現「有新版本」，按「立即更新」，約 1～2 分鐘後頁面會自動重新整理。

* **小更新包**（`PCG-Update-….exe`，約 10 MB）：先關掉 PCG 會議翻譯 → 點兩下小更新包 → 一樣出現藍色視窗就按「其他資訊」→「仍要執行」→ 約 1 分鐘完成。
  * 如果出現「這次更新包含新的套件或模型」，代表這次必須用完整安裝檔。
* **完整安裝檔**：直接裝在舊版上面即可。
* IT 大量派送（不跳任何視窗）：在 exe 後面加 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`。
* 發布頁上的 `.sha256` 檔是更新包的「指紋」，用來確認檔案完整、沒被改過，**同仁不用下載**。
  * IT 把小更新包放到公司共用資料夾時，`.exe` 和同名的 `.sha256` 要**一起放**：一鍵更新會先比對指紋，不符就不安裝（例如下載被截斷）。
  * 從 GitHub 一鍵更新不需要這個檔，程式會直接讀發布頁上的指紋。

## 五、遇到問題

* 安裝失敗：把 `D:\PCG-live-whisper\group_data\install.log`（更新失敗是 `update.log`）交給 IT。
* 程式用到一半出問題：按頁面最下方的「回報問題」→「產生診斷檔」，把下載的 zip 寄給 IT。
* 防毒軟體攔截：請 IT 把安裝資料夾加入例外。
* 解除安裝：Windows「設定」→「應用程式」→「PCG Meeting Translator」→「解除安裝」。錄音、逐字稿、設定會留在資料夾裡，確定不要了再手動刪除。

## 給 IT

* **IT 設定頁**：在同仁電腦上點操作頁面最下方的「IT 設定」，或直接打開 `http://localhost:19781/simple/admin`。
  * 第一次：在那台電腦上設定 IT 密碼（至少 6 個字），之後每次進入都要輸入。同仁不需要知道這組密碼。
  * 可以改：本機／伺服器模式、大模型（集團 Open WebUI、內部伺服器、外部 AI 服務）與 API 金鑰、GPU 伺服器、辨識模型、同仁密碼、允許其他電腦看字幕。
  * 存檔就生效，不用重裝。詳細說明見 [INSTALL.md](INSTALL.md)。
* 安裝檔與小更新包的製作方式：見 [windows/README.md](windows/README.md)。
